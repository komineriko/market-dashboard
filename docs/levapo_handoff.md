# レバポ 引き継ぎメモ（2026-09-23 時点）

「レバポ」= ユーザーが名付けた、SPY または XSP を 14DTE でエントリーし IV 上昇による利益を狙う 3脚Put 戦略。

## 1. 戦略の正確な定義（Delta の解釈は過去に何度も訂正あり。この定義で固定）

| 脚 | 決め方 | 実質 | 売買 |
|---|---|---|---|
| ① | **Call Δ +0.90** となるストライク K1 の **Put** | Put Δ ≈ −0.10（OTM） | Long 1 |
| ② | **Call Δ +0.15** となるストライク K2 の **Put** | Put Δ ≈ −0.85（深いITM） | Short 1 |
| ③ | K1 < K3 < K2 の Put。固定Δで決めない | ATM より少し下が望ましい | Long 1 |

- ③の条件: **SPY 1セット（×100）の満期最大損失 < $2,500**。可能なら ATM より下のストライクから選ぶ。
- 手順: ①②を Delta で決定 → 実プレミアム取得 → ③候補を 1 ストライクずつ試す → 満期 payoff を計算 → Max Loss < $2,500 を確認。
- ストライク順は K1 < K3 < K2。初期 Net Delta はプラスになりやすい（例: ③が −0.40Δ なら −0.10 + 0.85 − 0.40 = +0.35）。
- Net Vega = Vega① − Vega② + Vega③。Long になる「可能性が高い」だけで、**実チェーンの Greeks で必ず確認する**こと。

## 2. ユーザーの厳守事項

- データは **MF-Boost Option Info（https://mf-boost.com/option-info/）の SPY 実チェーン**を優先する。
- 必要な項目: Expiration, DTE, Strike, Call/Put Delta, Call/Put IV, Bid, Ask, Mid, Gamma, Vega, Theta。計算は Bid/Ask の Mid で行う。
- **Black-Scholes の仮定値から作ったストライク例は採用しない**（以前の AI が出したものも無効）。
- 曜日は先入観で金曜を選ばず、実測で比べる。四半期 OPEX は最初から除外せず、別の群として測る。
- 勝率だけで判断しない。**上位5%の巨大利益を除いた期待値**を必ず出す。

2. 最大損失 < $2,500 を満たす最適な③

5. Quarterly OPEX（3・6・9・12月）を跨ぐべきか
6. 14DTE エントリー後、何 DTE で Exit するべきか（**7DTE Exit が重要候補**）
7. SPY と XSP のどちらが適しているか（SPY は②の早期割当てリスクあり。XSP はヨーロピアン・現金決済だが、流動性とスプレッドの比較が必要）

評価は Entry曜日 × OPEX区分 × マクロイベント（FOMC/CPI/雇用統計/PCE）× Exit DTE に分けて行う。利益が IV 由来か Delta/Gamma 由来かも P/L 分解で示す。

## 5. 実チェーンなしで確定している構造上の事実（数式で成立）

- ②Short + ③Long はブル・プット・スプレッド。レバポはそれに①Long を足した形。
- **満期最大損失 = (K2 − K3 + Net Debit) × 100**。満期で S が K1〜K3 の平坦区間にあるときに発生する。つまり最悪ケースは暴落ではなく**中程度の下落**。
- S ≥ K2 では損益 = −Net Debit（通常はクレジットなので利益）。S < K1 では下落するほど利益が 1:1 で増える。
- K3 を上げるほど最大損失は単調に減る。そのため ATM 付近の K3 では $2,500 制約はほぼ効かない。
- 合成チェーンでは Net Vega Long になり、Exit 7DTE では Delta+Gamma の寄与が Vega より大きかった。**いずれも実データでの検証前なので結論にしないこと。**

## 6. 前任 AI が置いた仮定（ユーザー未承認。必要なら確認）

- ③の採用ルール: 条件を満たし、かつ ATM 以下の候補のうち **Net Vega が最大のもの**。別案は「最大損失が $2,500 に最も近い最下位の K3」。表示は全候補を出す。
- 金利 r = 4.0%、配当利回り q = 1.2%（CLI の `--r` / `--q` で変更可）。
- 途中時点の再評価はヨーロピアン BS、IV は全脚に同じ幅の平行シフト（sticky strike）。スキュー変化と早期行使価値は含まない。
